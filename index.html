⚙️ Conectar Google Sheets

Pega aquí la URL de tu Web App de Google Apps Script. La app la guarda en este navegador para no pedirla cada vez.

📋 Configuración rápida

1. Crea una hoja de cálculo en Google Sheets. 2. Abre Extensiones → Apps Script. 3. Copia el archivo apps-script/Code.gs de este proyecto. 4. Ejecuta setup() una vez y autoriza. 5. Ve a Implementar → Nueva implementación → Aplicación web. 6. Ejecutar como tú y acceso: cualquiera con el enlace. 7. Copia la URL /exec y pégala arriba.
